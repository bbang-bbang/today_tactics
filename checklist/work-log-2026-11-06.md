| 프리셋 | TERA 판정 | 근거 / 조치 |
|--------|----------|------------|
| bump | PASS | `curveType:'monotone'` 필요(기본 smooth 는 고리 모양 overshoot), y축 `labels.formatter` 로 'N위'. 12팀 전부 컬러면 스파게티 → **Phase 1 기본 하이라이트 필수** |
| quadrant (산점도) | PASS (우회) | 점별 색·마커 외곽선 무시 → 팀마다 series 1개, 어두운 팀 색은 배경 대비 3:1 까지 밝힘(`util.lighten`). 라벨 `pointLabels`, y=x·사분면 라벨은 비율좌표 `annotations`(축 min/max 고정 필요). S 카드는 좁음 → M 이상 |
| forest | **FAIL → 자체 Canvas** | range-bar/boxplot/dumbbell 모두 기준선(plotLines) 미표시, boxplot 은 소수 눈금 반올림. 어댑터 `drawForest()` 로 대체(TERA 불필요, 번들 실패 시에도 렌더) |
| dumbbell | PASS | 행 12개면 라벨이 빽빽 → **카드 높이를 행 수에 비례** (Phase 1 어댑터 옵션) |
| heatMatrix | PASS | `data` 는 최상위에 둬야 함(series 안은 무시). 행 12개 × 320px 이면 셀 높이 부족으로 값 라벨 숨김 → **행 수 비례 높이** |

**게이트 결과: 통과** (TERA 품질 미달 1종 < 2종). Phase 1 계획 입력:
1. 어댑터에 행 수 기반 자동 높이(`opts.rowHeight`) 추가 — dumbbell·heatMatrix·forest.
2. bump 는 기본 highlight(상위 3 + 하위 2 또는 선택 팀) 로 렌더.
3. forest 는 Canvas 렌더러 유지 — 툴팁(hover) 은 Phase 1 에서 추가 필요(현재 없음).
4. DPR: TERA 가 canvas 속성을 자체적으로 ×dpr 처리 — 어댑터는 CSS px 만 전달.
